Copias de seguridad

Respaldo manual y automático de la base de datos MySQL completa.

El sistema revisa los respaldos al iniciar y mientras permanece abierto. Si han transcurrido 24 horas desde la última copia, genera una automática. Conserva las 3 copias normales más recientes. Se guarda una copia adicional de emergencia antes de restaurar.

La carpeta contiene archivos .sql y sus metadatos .json. Para conservar una copia fuera del equipo, copia ambos archivos a una memoria USB o unidad externa segura. Las copias no están cifradas: protégelas del acceso no autorizado.

Restaurar copia de seguridad

Atención: esta operación reemplaza los datos actuales.

Se perderán los cambios realizados después de la fecha del respaldo elegido. Antes de importar, el programa crea una copia de recuperación del estado actual. La restauración de tablas SQL no es atómica; si falla, se intentará recuperar el estado anterior y se requerirá revisar la base de datos.

Se verificará su integridad SHA-256 antes de importarla.
